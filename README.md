Place a CSV named `engine_sensor_data.csv` here to use your own data.

Required columns:
- temperature
- pressure
- vibration
- oil_quality
- operating_hours
- remaining_useful_life

The app generates clearly labelled synthetic demonstration data if the file is absent. For a serious portfolio project, use a permitted public turbofan dataset such as NASA C-MAPSS and document how its cycle-based target maps to your chosen prediction task. Do not present synthetic demo metrics as real-world results.
